Sunset City Cover Maker — a GTA-style cover art maker that runs entirely offline in your browser. Load your own photos (read locally, never uploaded), drag to crop and scroll to zoom each panel, arrange them in a five-panel cover grid or a simpler layout, edit the caption, apply a Vice City sunset or neon colour grade, and export 1080×1080, 1080×1350 or 1920×1080 PNGs.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
